# Enterprise AI Assistant

An enterprise-style AI assistant built while learning AI Engineering from scratch.

## Current Features

- Gemini 2.5 Flash integration
- FastAPI backend
- Conversational memory
- PostgreSQL chat history
- PDF upload and processing
- ChromaDB vector database
- Semantic search
- Retrieval Augmented Generation (RAG)
- Session-based document isolation
- Re-ranking using Cross Encoders

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Gemini API
- ChromaDB
- Sentence Transformers

## Architecture

User
→ FastAPI
→ Memory Layer
→ Vector Retrieval
→ Re-ranking
→ Gemini
→ Response
